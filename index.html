Roboflow Inference SDK

Run Workflows on live video with Roboflow Cloud Streaming.

  • Webcam: publish this browser's camera with startStream({ source: mediaStream }) and play the annotated video.
  • Registered source: run a Workflow on a camera registered in your workspace, or attach to a running job with attachStream.

Both pages take an API key for quick tests. Leave it empty to go through examples/proxy-server.mjs (npm run build, then ROBOFLOW_API_KEY=... node examples/proxy-server.mjs), the pattern to use in production.
